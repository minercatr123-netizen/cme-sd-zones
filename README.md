# CME SD Zones สำหรับ MT5 (ทอง XAUUSD / GOLD)

โซน ±1/2/3 SD จากออปชันทองของ CME (QuikStrike Vol2Vol) วาดบนกราฟ MT5 พร้อมตาราง Future / CFD
ค่าอัปเดตจากศูนย์กลางที่เดียว ทุกคนที่ใช้เห็นค่าชุดเดียวกันภายในไม่กี่นาที
ตัวนี้วาดโซนอย่างเดียว ไม่เปิดออเดอร์

## ⬇️ ดาวน์โหลด
**[CME_SD_Zones_Share.ex5](https://github.com/minercatr123-netizen/cme-sd-zones/raw/main/CME_SD_Zones_Share.ex5)** (กดแล้วโหลดได้เลย)

## ติดตั้ง
1. MT5 > File > Open Data Folder > MQL5 > **Experts** > วางไฟล์ `CME_SD_Zones_Share.ex5`
2. Navigator > คลิกขวา Expert Advisors > Refresh
3. **(ครั้งแรกครั้งเดียว)** Tools > Options > Expert Advisors > ติ๊ก "Allow WebRequest for listed URL" แล้วเพิ่ม `https://raw.githubusercontent.com`
4. ลาก `CME_SD_Zones_Share` ลงกราฟทอง แล้วกด OK

ตารางลากย้ายได้ด้วยเม้าส์ ค่าอัปเดตเอง ไม่ต้องทำอะไรเพิ่ม

ข้อมูลนี้ใช้ประกอบการตัดสินใจเท่านั้น ไม่ใช่คำแนะนำการลงทุน
