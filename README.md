# CME SD Zones สำหรับ MT5 (ทอง XAUUSD / GOLD)

โซน ±1/2/3 SD จากออปชันทองของ CME (QuikStrike Vol2Vol) วาดบนกราฟ MT5 พร้อมตาราง Future / CFD
ค่าอัปเดตจากศูนย์กลางที่เดียว ทุกคนที่ใช้เห็นค่าชุดเดียวกันภายในไม่กี่นาที
ตัวนี้วาดโซนอย่างเดียว ไม่เปิดออเดอร์

## ดาวน์โหลด
[CME_SD_Zones_Share.zip](https://github.com/minercatr123-netizen/cme-sd-zones/raw/main/CME_SD_Zones_Share.zip)

## ติดตั้ง (3 ขั้น)
1. MT5 > File > Open Data Folder > MQL5 > Experts > วางไฟล์ `CME_SD_Zones_Share.ex5` แล้ว Refresh ใน Navigator
2. Tools > Options > Expert Advisors > ติ๊ก "Allow WebRequest for listed URL" แล้วเพิ่ม `https://raw.githubusercontent.com`
3. ลาก `CME_SD_Zones_Share` ลงกราฟทอง (แนะนำ M5 หรือ M15) แล้วกด OK

รายละเอียดเพิ่มเติมอยู่ในไฟล์ `วิธีติดตั้ง.txt` ใน zip

ข้อมูลนี้ใช้ประกอบการตัดสินใจเท่านั้น ไม่ใช่คำแนะนำการลงทุน
